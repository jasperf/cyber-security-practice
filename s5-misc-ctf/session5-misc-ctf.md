## Section A: Challenge Categories

**Key ideas:** CTF challenges cluster into a handful of recognisable categories — web, cryptography, reverse engineering, vulnerability exploitation, and flag retrieval — each demanding a different toolkit.

### Questions

- A) Analyse malware behaviour
- B) Find and exploit vulnerabilities to gain access to sensitive data or elevate privileges
- C) Crack a password or decode an encrypted message

**Q2** (1 mark)

- A) Exploit a live web vulnerability
- B) Analyse a malware/binary sample to understand its behaviour and identify vulnerabilities
- C) Decode a Base64 string
